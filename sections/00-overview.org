* Experiment

This report measures how much observable reasoning work can be moved from a language model into a Prolog-backed recursive runtime while preserving task success.

The benchmark is built around capability substitution, not vague claims that symbolic systems somehow contain a percentage of "reasoning." The useful measurements are success, token use, model calls, Prolog calls, latency, cost, recursion depth, and failure behavior.
